# Qolly

Suíte de pequenas melhorias para o **WoW Forever**: painel na casa de leilão (melhorias de
equipamento, vendas, oportunidades de lucro), treino no grimório com os tomos do bruxo,
quests de masmorra com o passo da cadeia, aviso de buffs e bônus de XP, coleta no
minimapa, lucro de receitas, placas, radar e mais.

![Qolly](docs/logo.png)

Descrição completa (português e inglês): [docs/curseforge.md](docs/curseforge.md).
Mudanças: [CHANGELOG.md](CHANGELOG.md). Créditos: [CREDITS.md](CREDITS.md).

## Instalar

Copie a pasta `Qolly` para `World of Warcraft/_forever_/Interface/AddOns/` e reinicie o
jogo. Digite `/qolly` para os comandos.

Para desenvolver: `install.ps1` liga esta pasta à pasta de addons do jogo (junction).
